where customers can buy books of various kinds.

Software Used:
PostgreSQL: to create and manage database
Node.js: to create the backend server and link it to database
HTML, CSS, JavaScript: to create the front-end webpages for the system.

Web-host:
Render.com was used to host all the database system, back-end and front end technology online.

Getting into Customer Page:
	-Register you account as buyer by filling the credentials(user-name, password, full name, email, mobile no,address) in login page
	-Login into the page by filling the user-name and password
Customer page: Here the customer can search for books of various kind, find the categories of books, view the details of a specific book,
	 Add a book to the cart and buy the  books. Customer can also navigate to my profile button and log out.

Getting into Seller Page:
	-Register you account as seller by filling the credentials(user-name, password, full name, email, mobile no,address) in login page
	-Login into the page by filling the user-name and password
Selelr page: Here the seller can search for books, add the books, manage the books and delete the books.
	 Seller can check the customer ordrers and can accept or remove the orders.
	 Seller can also navigate to my profile button and log out.

Any changes made to both the pages are automatically updated in the database.
